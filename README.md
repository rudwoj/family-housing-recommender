# 🏡 가족 맞춤 주거지 추천 (Multi-Person Weighted K-NN)

가격을 **완전히 배제**하고, 주택의 공간 조건(**공통 데이터**)과 가족 구성원이 직접 입력한
목적지까지의 **이동 시간**(**개별 데이터**)만으로 최적 주거지를 추천하는 웹 애플리케이션.
이동 지표는 거리(m)가 아니라 전부 **분 단위 시간**이다.

```bash
pip install -r requirements.txt
python data/generate_mock_data.py --n 400 --seed 42
streamlit run app.py
python tests/test_model.py
```

## 데이터 구조

| 구분 | 항목 | 비고 |
|---|---|---|
| **공통** (거리 계산) | 전용면적, 방 개수, 주차 가능 대수, 향, **버스·지하철역까지 도보 시간(분)** | 가족 공유 조건 |
| **개별** (거리 계산) | 구성원이 입력한 목적지까지 **차 / 대중교통 / 도보 시간(분)** | 목적지·이동수단을 각자 선택 |
| **부가** (계산 제외) | 준공년도, 층, 녹지 비율, 단지 규모, 일조, 소음 | 하드 제약·표시·안정성 지수 전용 |
| **가격** | 사용하지 않음 | `assert_no_price_columns()` 가 유입 차단 |

목적지는 앱에서 프리셋 선택 또는 좌표 직접 입력으로 바꿀 수 있고, 바뀌면 이동 시간이 즉시 재계산된다.
`src/travel.py` 의 Provider 를 갈아끼우면 실제 경로 API 로 대체된다
(`KAKAO_REST_API_KEY`, `ODSAY_API_KEY`; 키가 없거나 실패하면 거리 기반 추정으로 폴백).

## 파이프라인

```
① 하드 제약 + 백오프  →  ② 클리핑 → 스케일링 → KNNImputer
→ ③ 비선형 효용 변환  →  ④ 가중 유클리드 K-NN  →  ⑤ 이해충돌 해소
```

### ① 0건 조회 방지 — 백오프(Back-off)
후보가 `min_candidates`(기본 5) 미만이면 자동으로 제약을 완화한다.
- `locked` 제약은 절대 건드리지 않음 (예: "방 3개는 사수")
- `priority` 가 높은(=덜 중요한) 제약부터 완화 — 준공년도 → 주차 → 면적 순
- **실제로 후보를 막고 있는(binding) 제약만** 완화해 헛수고를 피함
- 완화값이 데이터 실제 범위를 벗어나면 즉시 완전 해제

### ② 이상치 대응
초대형 평수 같은 극단값이 MinMax 스케일을 독점해 일반 매물을 0~0.1 에 뭉개는 문제를
상·하위 클리핑과 RobustScaler 로 막는다. 실측(이상치 1.5% 포함, 전용면적 기준):

| 설정 | 일반 매물 분포 폭 (p5~p95) |
|---|---|
| MinMax, 클리핑 없음 | **0.140** ← 변별 불가 |
| MinMax + 1% 클리핑 | 0.264 (이상치 비율 미달) |
| MinMax + 2% 클리핑 | 0.707 |
| **RobustScaler (기본값)** | **0.607** (클리핑 비율과 무관하게 안정) |

클리핑 비율이 이상치 비율보다 낮으면 MinMax 는 여전히 눌리므로 **RobustScaler 가 기본값**이며,
분포가 눌린 피처는 앱이 자동 감지해 경고한다.

### ③ 비선형 효용 (Utility Function)
유클리드 거리는 모든 변화를 선형 취급하지만 사람의 만족도는 그렇지 않다.

| 유형 | 곡선 | 의미 |
|---|---|---|
| 이동 시간, 역까지 도보 | **볼록(convex)** `u = 1 − t^γ` | 50→60분이 10→20분보다 훨씬 괴롭다 |
| 전용면적, 방 개수, 주차 | **오목(concave)** `u = t^(1/γ)` | 60→70m² 가 130→140m² 보다 만족 증가폭이 크다 |

도보(γ=2.2) > 대중교통(1.8) > 차(1.7) 순으로 곡률이 가파르다.
변환 후 모든 피처는 **만족도 0~1(1이 최선)** 이 되므로 이상점은 전 차원 1 벡터이고,
거리 `d = √(Σ ω(1−u)²)` 는 자연히 0~1 에 놓여 `종합 적합도 = (1−d)×100` 이 된다.

### ④ 가중치 결합
$$\omega_c = \alpha\frac{W_c}{\sum W_c},\qquad
  \omega_{i,f} = (1-\alpha)\frac{P_i}{\sum_j P_j}\cdot\frac{W_{i,f}}{\sum_g W_{i,g}},\qquad \sum\omega = 1$$

### ⑤ 이해충돌 해소 — 어중간한 타협안 방지
단순 가중 합은 "누구도 만족 못 하는 평균적인 집"을 최적점으로 둔갑시킨다. 세 장치로 막는다.

1. **구성원별 만족도 하한선** — 각자 "이 밑은 안 된다"를 걸면 그 조건을 통과한 매물 안에서만 최적화
2. **파레토 최적 분석** — 다차원 비지배 해 + 선택한 두 구성원 평면의 2D 프론티어
3. **개인 Top-N 교집합** — 각자 독립적으로 뽑은 상위 매물의 교집합을 별도 표시.
   교집합이 없으면 "선호가 실제로 상충한다"고 명시하고 파레토 프론티어로 안내

여기에 사회적 선택 규칙 3종(공리주의 / 롤스적 Maximin / 형평성)의 최선안을 나란히 비교한다.

## 파생 지표

| 지표 | 정의 |
|---|---|
| `burden_min__*` | 구성원별 체감 이동 부담(분) = 활성 목적지 이동시간의 가중 평균 |
| `travel_mean_min` / `travel_std_min` | 가족 평균 이동시간 / 구성원 간 표준편차 |
| `inequality_index` / `equity_index` | 이동 부담 변동계수 / `1 − CV` (높을수록 균등) |
| `stability_index` | 녹지·연식·단지규모·일조·소음 가중 합성 (0~1) |
| `sat_min` / `sat_gap` | 최약자 만족도 / 구성원 간 만족도 격차 |
